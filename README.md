# Bricky for Windows

Download the executable for your system from [the latest release](https://github.com/hikarixyzX/Bricky-Releases/releases/latest):

- **Most Windows PCs:** `bricky-windows-amd64.exe`
- **Windows on ARM:** `bricky-windows-arm64.exe`

Keep the executable in a writable folder. Bricky checks for updates only when you start it and automatically restarts after installing an update.

This repository contains compiled executables, version metadata, and release automation only. The application source code is private.
